# Technical Figures

## Purpose

This directory stores figures generated from engineering analyses, laboratory results, calculations, geological interpretation and technical documentation.

## Content

| File | Description |
|------|-------------|
| mineralization-model.png | Mineralization interpretation |
| rock-classification.png | Rock mass classification |
| stress-distribution.png | Engineering calculations |
| sampling-results.png | Sampling visualization |

## Accepted Formats

- PNG
- JPG
- SVG
- PDF

## Naming Convention

```
<subject>-<description>.<extension>
```

Examples

```
rock-classification.png
sampling-results.jpg
stress-distribution.svg
```

## Guidelines

- Every figure must be referenced in the documentation.
- Include captions where applicable.
- Avoid low-resolution images.
