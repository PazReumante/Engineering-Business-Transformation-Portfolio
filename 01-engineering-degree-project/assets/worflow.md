# Project Workflow

## Purpose

This directory contains workflow diagrams describing the engineering process followed during the project, from field investigation to final technical conclusions.

## Typical Workflow

```
Project Definition
        │
        ▼
Literature Review
        │
        ▼
Field Investigation
        │
        ▼
Geological Mapping
        │
        ▼
Data Collection
        │
        ▼
Technical Analysis
        │
        ▼
Engineering Interpretation
        │
        ▼
Solution Development
        │
        ▼
Validation
        │
        ▼
Final Report
```

## Content

| File | Description |
|------|-------------|
| project-workflow.drawio | Complete project workflow |
| engineering-process.png | Engineering methodology |
| fieldwork-process.svg | Field inspection workflow |
| analysis-pipeline.png | Technical analysis pipeline |

## Accepted Formats

- Draw.io (.drawio)
- SVG

- PDF

## Naming Convention

```
<process>-workflow.<extension>
```

Examples

```
project-workflow.drawio
engineering-process.png
analysis-pipeline.svg
```

## Guidelines

- Workflows should be sequential and easy to understand.
- Maintain consistent symbols and colors.
- Prefer editable formats (Draw.io) alongside exported images.
