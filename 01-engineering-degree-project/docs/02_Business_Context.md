# Contexto del proyecto

El proyecto de titulación analizó la factibilidad de una operación chilena de pequeña minería de cobre. Los intentos previos de extracción motivaron una evaluación que integrara geología, diseño minero, costos y cierre antes de considerar una inversión.

Consulta el [resumen del caso](../README.md) y la [nota técnica](technical-analysis.md).
