# Project Objectives

## General Objective

Desarrollar una propuesta técnicamente viable basada en criterios de ingeniería para resolver un problema real del sector minero.

---

## Specific Objectives

- Comprender el contexto operacional.
- Analizar la información disponible.
- Evaluar alternativas técnicas.
- Diseñar una propuesta de mejora.
- Validar técnicamente la solución.
- Documentar el proceso de ingeniería.
