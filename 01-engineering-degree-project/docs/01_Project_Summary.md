# Project Summary

## Overview

Este proyecto corresponde al Trabajo de Fin de Grado desarrollado para la obtención del título de Ingeniera en Minas.

Se desarrolló sobre un caso real del sector minero, aplicando metodologías de ingeniería para analizar un problema operacional, evaluar alternativas y diseñar una solución técnicamente viable.

Más allá del resultado académico, este proyecto representa el inicio de una forma de trabajo basada en el análisis estructurado, la toma de decisiones fundamentada y la resolución de problemas complejos.
